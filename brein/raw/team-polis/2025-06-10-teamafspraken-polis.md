# Teamafspraken Team Polis (juni 2025)

Opgesteld door: Team Polis, tech lead Wouter Brouwer

1. We werken met feature branches en pull requests. Minimaal één reviewer.
2. We bouwen op Java 17 met Spring Boot 3.
3. Elke API-wijziging begint met een aanpassing van de OpenAPI-specificatie.
4. De pipeline blokkeert bij kwetsbaarheden met een CVSS-score van 9.0 of hoger. Lagere scores pakken we op in de sprint erna. (Afgesproken omdat de build te vaak stil lag.)
5. Releases op dinsdag en donderdag.
