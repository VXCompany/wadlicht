# Wadlicht in het kort

> Wadlicht Verzekeringen is een **fictief bedrijf**, bedacht voor demonstraties. Alle namen, regels en cijfers zijn verzonnen.

| | |
|---|---|
| Soort | Schadeverzekeraar (geen leven, geen pensioen) |
| Vestiging | Harlingen, met een kantoor in Leeuwarden |
| Medewerkers | 420 |
| Opgericht | 1911, als onderlinge van vissers, schippers en havenbedrijven |
| Klanten | Particulieren en ondernemers (handel, haven, agrarisch, bouw) |
| Toezicht | DNB (prudentieel) en AFM (gedrag), zie [[toezicht-en-regelgeving]] |

- Autoverzekering (WA, beperkt casco, allrisk)
